# nutrione

A personal health operating system: nutrition, fitness, sleep, and health
scoring, with an optional local-LLM AI coach.

- `backend/` — Express + TypeScript API (Postgres, Redis, JWT auth)
- `web/` — React + Vite + TypeScript frontend
- `docs/API.md` — full API reference
- `QUICKSTART.md` — local setup and run instructions
- `RENDER_DEPLOY.md` — deploy to Render.com (free tier)
- `docker-compose.yml` — Postgres, Redis, Ollama, MinIO, and the API
